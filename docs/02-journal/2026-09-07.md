## 2. Appris

- Un PCB (Printed Circuit Board) permet de relier physiquement des composants électroniques entre eux sans câblage volant.
- KiCad est un logiciel libre de conception électronique (schématisation puis routage de circuits imprimés).
- La schématisation est la première étape avant le routage : elle définit les connexions logiques entre composants avant leur placement physique sur le PCB.
